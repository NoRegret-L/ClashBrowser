# Phase 2 routing policy
Three modes: smart, global, strict. Global retains user overrides and ad-block; private/LAN reject stays until stage 3. Custom DOMAIN, DOMAIN-SUFFIX, IP-CIDR, IP-CIDR6; first match, no-resolve for IP. Private app JSON file only stores routing policy, not subscriptions. Save uses temporary file/rename; invalid stored policy falls back to strict and displays a warning. Missing storage is explicitly session-only. Browser shortcut closes native view first; returns to strategy editor, then stops/starts core on save; browser must be reopened manually. No hot reload. Native route inspector queries Mihomo statistic.DefaultManager live trackers filtered by inbound and exact host. Only actual match type/payload displayed; closed and rejected flows may have no observation, no inference or controller. Full rejected-flow event hook, private network access, online updates, secure subscription storage, and real-device network isolation remain outstanding. Verify with three-platform CI. Native route statistics can change during concurrent flows; not a per-navigation attribution guarantee.
