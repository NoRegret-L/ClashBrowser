# Experimental browser and incremental CI

Android uses the official AndroidX ProxyController and WebView; HarmonyOS uses ArkWeb ProxyController with implicit bypass rules cleared; iOS uses a nonpersistent WKWebsiteDataStore and Network.framework HTTP CONNECT proxy with explicit credentials and failover disabled. The native screens have an address bar and close button. No VPN service, system proxy, or TUN setup is added. The shared Dart screen keeps the core running while the browser is open. Android/HarmonyOS only attempt local proxy authentication on an exact loopback host and empty realm, never on an arbitrary origin; those APIs lack a reliable isProxy flag and may not deliver CONNECT authentication callbacks. HTTPS-only top-level navigation, disabled JavaScript (including WebRTC), no downloads or permissions. Site compatibility is intentionally limited. The native screens are experimental: compile success is not proof of no leakage. Device tests must validate auth, redirects, subresources, DNS/prefetch, media and failure paths before use with sensitive data. The browser has not yet been tested on devices.

CI: daily PR/push uses the embedded application workflow instead of duplicate base builds. Three native build outputs are cached by exact runner OS/architecture, upstream manifest, local core source and workflow hash; no fallback cache keys. Cached or fresh SDK checksums are checked before packaging. Native compilation occurs on cache miss and on changes to inputs. Host routing regression runs every time; application builds still test Dart on every platform. Flutter and OHOS Docker layer caching are enabled. A cold cache can be seeded from the specific verified run 45960747868 only when all core source paths and pinned native build steps match exactly; its artifact must still exist and pass checksum verification. Otherwise the workflow rebuilds. Cache entries may be evicted and Docker cache transfer may outweigh benefit; actual savings need measured subsequent runs. Baseline workflow remains manually runnable. No signing or credentials added.
