# Native routing decision observation
A narrow build-time callback at Mihomo's actual match result, before dial: records matched rule type, payload and selected policy, including REJECT and completed short-lived connections. No rule evaluation, DNS request, route change, logs, or external controller. The installer requires exactly one match anchor in the pinned derivative, patches a private copy for Android, the existing patched copy for OHOS, and the checkout for iOS. The patch is part of corresponding-source materials. Uses a session-specific inbound name, memory-only bounded 256-record ring, no URL/path/credentials; old session records cannot be selected by a new session. Resource cap is not a routing parameter. Query is exact domain only, newest first, deduplicated. Decision does not attest successful dialing, page ownership, or absence of leaks. IPv4/IPv6 UI inspection and LAN support remain phase 3. Regression covers rejected and completed flows and clearing across restart. Requires host and all native builds to pass before merging into dev.
