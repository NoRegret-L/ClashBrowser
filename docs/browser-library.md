# Shared tabs, history and bookmarks

Flutter owns all logical tab ids, selected tab, last successfully reported navigation URL and UI. A single active native view is retained: switching/new tab/closing active tab requires native close acknowledgement, then remounts with the same authenticated endpoint, waits for proxy readiness, and restores the selected tab URL. Inactive tabs have no live renderer or background requests from an owned view. Back/forward stack, form state, and scroll position are not preserved across switches. Stale callbacks from prior generations are ignored. This is logical multi-tab, not concurrent native WebViews; native renderer drain and process-level network isolation still require device tests.

History is recorded from a native page-finished URL event, not a typed address, and ignores known load/auth errors. The event is not proof of a successful HTTP status. Favorites toggle on the last reported URL. Both use one versioned local JSON file in private app storage, with serialized writes and same-directory temporary-file replacement. Query strings and fragments are stripped to reduce token retention; URL paths and hosts remain sensitive. No node credentials, no proxy credentials, no sync, no automatic history upload. Unavailable/corrupt storage falls back to current-session data and is visibly identified; corrupt data is not overwritten. Clearing history and removing bookmarks updates local storage, but this does not claim to clear native WebView cookies or caches.

Flutter IndexedStack was considered but would retain multiple live platform views and complicate application-wide proxy lifecycle on Android/OHOS. The official shared_preferences/path_provider plugins and HarmonyOS implementations were reviewed; the OHOS package support for our exact toolchain is not established. Use existing platform private-directory APIs only; no new dependency or new native proxy logic. The only native change is a directory MethodChannel on each platform. Native adapter and device security tests remain required. No tuning weights or arbitrary tab caps added.
